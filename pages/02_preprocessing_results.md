## Fatigue Index (피로도 지수)

**정의**: 후반 10K(30K→40K) 구간의 페이스 ÷ 초반 10K(0K→10K) 페이스

```
Fatigue_Index = (40K_s - 30K_s) / 10  ÷  (10K_s / 10)
              = 후반 10K 페이스(sec/km) / 초반 10K 페이스(sec/km)
```

| 해석 | 의미 |
|------|------|
| FI = 1.0 | 초반과 동일한 페이스 유지 |
| FI > 1.0 | 후반부 페이스 저하 (히팅 더 월 가능성) |
| FI < 1.0 | 후반부 페이스 향상 (네거티브 스플릿) |

### 분포 통계

```
Fatigue Index 평균:   1.126
Fatigue Index 중앙값: 1.094

FI > 1.1  (페이스 10% 이상 저하):  47.9%  → 전체 러너의 절반 가까이
FI > 1.2  (페이스 20% 이상 저하):  20.5%  → 5명 중 1명이 심각한 페이스 저하 경험
```

평균 Fatigue Index 1.126은 대다수 러너가 후반부에 페이스가 느려짐을 의미합니다. 이는 **히팅 더 월** 현상이 보스턴 마라톤에서 광범위하게 발생함을 확인합니다.

## 구간별 평균 페이스 (Hitting the Wall 시각화)

| 구간 | 평균 페이스 | 초반 대비 변화 |
|------|-------------|----------------|
| 0–5K | 5:06 /km | 기준 |
| 5–10K | 5:02 /km | -4초 (워밍업 효과) |
| 10–15K | 5:05 /km | +3초 |
| 15–20K | 5:12 /km | +10초 |
| 20–25K | 5:17 /km | +15초 |
| 25–30K | 5:32 /km | **+30초** ← 페이스 저하 시작 |
| 30–35K | **5:44 /km** | **+42초** ← 히팅 더 월 |
| 35–40K | 5:42 /km | +40초 |

25K 이후 페이스가 급격히 떨어지며, 30~35K 구간에서 가장 큰 저하폭(초반 대비 +42초/km)을 보입니다. 이 지점이 **히팅 더 월**의 전형적인 발생 구간입니다.

## Pacing Variance (페이스 일관성 지표)

구간별 페이스(sec/km)의 표준편차로 계산합니다. 값이 작을수록 일정한 페이스를 유지한 러너입니다.

```
Official Time과의 상관계수: 0.412
→ 페이스 편차가 클수록 완주 시간이 느린 경향
```
